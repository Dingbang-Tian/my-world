# S07：接入 OpenAI Chat 协议

## 本阶段解决什么

`OpenAiChatGateway.generate` 只处理一次 Chat Completions 请求。它按 `ModelRequest.modelId` 从不可变注册表选出实例，合并实例默认值与本次 `ModelOptions`，将 SYSTEM/USER/ASSISTANT/TOOL 消息和工具 JSON Schema 转成协议请求。工具结果保留 `tool_call_id`；助手历史保留完整工具调用。`reasoning_content` 仅在兼容供应商明确需要时通过 `forward-reasoning-content` 回传，默认关闭。模型实例包含独立的供应商标识、完整 endpoint、服务端模型名和密钥；密钥不进入 `toString` 或错误响应。

网关用 JDK HttpClient 读取 SSE；按 `tool_calls[].index` 聚合跨片 id、名称和 arguments，输出 `TextDelta`、`ReasoningDelta` 与尾块 `UsageReported`。必须同时看到结束原因和 `[DONE]` 后才发出唯一 `TurnCompleted`，其中包含完整助手消息、标准化结束原因和最终 token 用量。流中的空 delta 被忽略；未知结束原因保留 `UNKNOWN`，由 Agent 拒绝当作正常回答。HTTP 401/429/500 和 EOF 断流进入错误回调，错误中不复制可能含敏感信息的服务端响应体。

`DefaultAgentRun` 仍是唯一工具循环。模型调用返回 `TOOL_CALLS` 后，Agent 校验参数并执行 Java 工具；失败的结构化 `TOOL` 结果交给模型修正。Agent 对推理文本和单次用量发布事件，并在最终 `AgentResult.usage` 中汇总已完成回合的用量。协议网关不持有 Java 工具实例，也不自行递归续问。

官方 Chat Completions 参考说明 `stream_options.include_usage` 会在 `[DONE]` 前追加一个 `choices` 为空的用量块；连接中断时可能收不到该块。本实现因此允许用量为空，但缺 `[DONE]` 时整体失败。参考：[Chat Completions API](https://platform.openai.com/docs/api-reference/chat/create)。

## 应用配置

`my-world-ai-app` 显式启用时装配一个 `ModelGateway` Bean；未启用时不影响现有 Spring AI 普通对话路径。以下只展示配置形状，真实密钥从环境变量传入：

```yaml
my-world:
  ai:
    chat:
      enabled: true
      models:
        codegen-main:
          provider-id: openai-compatible
          endpoint: ${CHAT_ENDPOINT}
          model: ${CHAT_MODEL}
          api-key: ${CHAT_API_KEY}
          temperature: 0.4
          max-completion-tokens: 2048
```

`endpoint` 是完整的 `/chat/completions` 地址。`ModelOptions` 的非空调用值只覆盖该次请求；共享模型配置不变。当前配置提供模型实例默认值；Agent 定义或会话层级的选项策略属于后续 S09/S16。

## 本地验证与轨迹

显式使用本机 JDK 21 执行 `mvn -q clean test`，全项目 45/45 通过，其中 S07 新增 5 个本地 HTTP fixture 测试。`OpenAiChatGatewayTest` 使用仅监听 `127.0.0.1` 的 HTTP 服务，验证跨片工具名/参数、多工具 index、推理文本、usage 尾块、历史中的工具调用与结果、401/429/500、断流、空 delta、未知结束原因，以及两个 modelId 与覆盖值隔离。`OpenAiChatAgentIntegrationTest` 让现有 Agent 真实访问本地 HTTP 服务，验证三次模型请求和一次 Java 工具执行：

```text
HTTP 1 → ASSISTANT bad:add({"a":2})
Agent → 参数校验失败，未执行 Java 工具
HTTP 2（带 TOOL bad/TOOL_VALIDATION_ERROR）→ ASSISTANT fixed:add({"a":2,"b":3})
Agent → 执行 Java 工具一次，返回 TOOL fixed/5
HTTP 3（带完整历史）→ ASSISTANT "5"，usage 总计 10
```

启动模块的 smoke 同时验证显式配置可装配 Chat 网关，原 `AiChatService` 仍使用 `SpringAiChatAdapter`。本阶段无真实供应商请求；供应商兼容性和特定 reasoning 字段需要独立冒烟证据，不能由本地 fixture 推断。
