## 调用链

应用配置 `my-world.ai.embedding.models.<modelId>` → `EmbeddingGateway.embed(EmbeddingRequest)` → `HttpEmbeddingGateway` 按 modelId 选择 OpenAI 文本或 DashScope 多模态协议 → 一次 HTTP 请求 → `EmbeddingResult`（向量索引、类型、维度、用量）。向量网关和聊天 `ModelGateway` 是不同接口与 Spring Bean；向量 modelId 不进入 Agent 工具循环。

`EmbeddingInput` 表示一个有序语义单元，可含文本、图片和视频片段。媒体支持 HTTPS URL、经校验的 data URI 和最多 10 MiB 的内存字节。OpenAI 文本协议仅接受独立纯文本输入，使用批量 `input` 和可选 `dimensions`，在联网前拒绝媒体与融合。DashScope 原生多模态协议使用 `input.contents` 和 `parameters.dimension`；独立模式分别编码各片段。融合能力由模型配置显式声明：需要 `enable_fusion=true` 的 Qwen3 VL 模式将一个语义单元的片段分别放入 `contents`；采用对象内融合的模型将其放在同一内容对象。不支持融合的实例在联网前拒绝请求。结果校验非空向量、有限分量、索引不重复、请求维度一致，并对 OpenAI 批量索引检查完整覆盖。`EmbeddingUsage` 分别保留可选的输入、输出、总量、图片和文本 token，不把 DashScope 总量误当成输入量。

应用配置例子：

```yaml
my-world:
  ai:
    embedding:
      enabled: true
      models:
        text-vector:
          protocol: openai
          endpoint: https://api.openai.com/v1/embeddings
          model: your-text-embedding-model
          api-key: ${OPENAI_API_KEY}
        visual-vector:
          protocol: dashscope
          endpoint: https://dashscope.aliyuncs.com/api/v1/services/embeddings/multimodal-embedding/multimodal-embedding
          model: qwen3-vl-embedding
          api-key: ${DASHSCOPE_API_KEY}
          fusion-supported: true
          fusion-parameter-required: true
```
