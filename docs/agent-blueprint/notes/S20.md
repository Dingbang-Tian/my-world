## 已实现的入口

- `AgentSdk.create(ModelGateway, AgentDefinition)` 在普通 JAR 中创建无工具的基础 `AgentService`。模型通过 `ModelGateway` 注入，不依赖供应商客户端或 Spring 容器。
- `CodegenSdk.readOnly(ModelGateway, modelId, workspace)` 创建绑定可信工作目录的只读 `CodegenService`；`CodegenService.agentService()` 供第二调用方直接使用同一代码生成 Agent 定义。需要写入、命令或计划能力时由可信装配使用 `CodegenFactory` 或 Spring 配置授予，HTTP 请求不能改变这些开关。
- `CodegenTaskService` 管理本进程句柄和 owner/requestId 幂等键；MySQL 模式还按数据库唯一请求键查询历史运行。相同请求返回同一 runId，内容或会话冲突返回 `REQUEST_ID_CONFLICT`。运行状态包含 `RUNNING`、终态结果和文件产物元数据。
- `CodegenController` 仅在 `my-world.codegen.enabled=true` 时生效；本地开发可由 `dev` profile 提供该开关和 ownerKey。输入字段白名单仅允许任务、requestId 与可选 sessionId；工作目录、工具、模板等额外字段直接拒绝。ownerKey 来自服务端配置。此入口尚未接身份系统，不作为公开多用户接口。

## 本地开发配置

在 `dev` profile 中配置可信模型网关和代码生成应用，例如：

```yaml
my-world:
  ai:
    chat:
      enabled: true
      models:
        local:
          provider-id: local
          endpoint: http://127.0.0.1:9000/v1/chat/completions
          model: local-model
          api-key: ${LOCAL_MODEL_KEY}
  codegen:
    enabled: true
    model-id: local
    workspace: /absolute/path/to/workspace
    write-enabled: false
    command-enabled: false
    plan-enabled: false
    sub-agent-enabled: false
```

可通过 `MYWORLD_CODEGEN_OWNER_KEY` 改变本地固定 owner。默认服务地址为 `127.0.0.1:8080`；`SERVER_ADDRESS` 和 `SERVER_PORT` 可覆盖。生产 profile 不注册这些路由。

## HTTP 流程

```text
POST /api/codegen/tasks
  {"requestId":"demo-1","task":"检查目录"}
  -> data.runId、data.sessionId、data.status

GET  /api/codegen/tasks/{runId}
  -> status、result、artifacts

GET  /api/codegen/tasks/{runId}/events?after=0
  -> text/event-stream；每条有 id=sequence、event=type、data=AgentEvent JSON
  -> 也接受 Last-Event-ID 以便重连

POST /api/codegen/tasks/{runId}/cancel
  -> 取消当前进程运行；SSE 断开本身不取消任务

POST /api/codegen/tasks/{runId}/resume
  {"requestId":"demo-resume-1"}
  -> 仅在 MySQL 持久化且原运行可安全恢复时创建关联新 run
```

历史运行的事件从数据库按序分页回放；进程内运行通过同一 `AgentRun` 监听。内存模式只支持当前进程的状态与事件，重启查询和恢复需要 MySQL。未知文件或命令副作用保持 `NEEDS_REVIEW`，不会自动恢复。单实例启动扫描的边界沿用 S19。

## 独立 Maven 消费者

在仓库外的临时目录 `/private/tmp/s20-sdk-consumer` 创建了独立 Maven 工程，仅声明 `com.dingbang:my-world-ai-agent:0.0.1-SNAPSHOT` 和 `com.dingbang:my-world-ai-app:0.0.1-SNAPSHOT` 为普通依赖。可复现源码保存在 [examples/sdk-consumer](../examples/sdk-consumer/)；它没有加入聚合生产模块。消费者只使用 `agent.api`、`codegen.api` 与 `aiframework.api/model`（含事件子包）的公开类型。假模型直接产生 `TurnCompleted`；一个测试调用 `AgentSdk.create`，另一个调用 `CodegenSdk.readOnly(...).agentService()` 执行与 HTTP 示例相同的“检查目录”任务。无需模型 Key，临时工程及仓库示例各自两个测试均通过。

复现命令（使用 JDK 21）：

```bash
mvn -pl my-world-ai-app -am -DskipTests install
mvn -f docs/agent-blueprint/examples/sdk-consumer/pom.xml test
```
