## 本阶段解决什么

最小调用链：Java `Tool<P>` → `ToolDescriptor` 从 `@ToolInfo/@ToolParam` 或显式 `descriptor()` 生成参数 JSON Schema → `ToolRegistry` 校验并冻结授权工具 → 模型的 `ToolCall(callId, name, argumentsJson)` → `ToolExecutor` 严格解析参数并调用 Java 工具 → 与 callId 配对的 `ToolResult`。执行阶段监听器依次看到 PREPARING、CALLING、COMPLETED；参数或执行失败时看到 FAILED。监听器抛异常不会改变工具结果。

`Tool<P>.parameterType()` 显式提供参数 `Class<P>`，避免试图从已擦除的泛型或桥接方法猜测。参数类必须有无参构造方法，非静态字段必须有 `@ToolParam`；支持字符串、整数、浮点、布尔、枚举、这些标量的一维数组和 `List<T>`。原始 List、嵌套对象、继承字段等目前明确拒绝。Schema 禁止额外字段；执行前检查必填、null、字段类型、枚举值和未知字段，然后用 Jackson 转为 Java 参数对象。模型可填写的 JSON 不含 `runId/sessionId/workspace/deadline`；它们只由可信调用方构造 `ToolExecutionContext`。

`ToolRegistry.select(names)` 可从注册表创建运行级授权快照。相同工具实例重复登记时去重，同名不同实例拒绝；未授权工具即使伪造名称也返回 `TOOL_NOT_FOUND`。普通参数错误返回 `TOOL_VALIDATION_ERROR`，Java 工具异常返回 `TOOL_EXECUTION_ERROR`，均映射到 framework 的 `ToolResultStatus.ERROR`。成功返回 `ToolResultStatus.SUCCESS` 和工具输出。当前没有把工具接入 `DefaultAgentRun`；模型提出工具调用时，S04 的无工具运行仍明确失败，S06 才负责追加 assistant/tool 配对消息并继续模型回合。

## 命名与包边界

对照用户举例的 `agent/client/AgentClient`、`LlmClient`、`model/AgentMessage/AgentResponse` 等名称，本项目已有职责更明确的区分：`ModelGateway` 是单次模型调用；`AgentService/AgentRun` 是 Agent 运行 API；`Message/ToolCall/ToolResult` 是协议中立的模型消息数据；`Tool/ToolRegistry/ToolExecutor` 是可信 Java 执行机制。`AgentResult` 包含运行终态、错误和模板版本，比单纯的 `AgentResponse` 更准确。`InMemoryAgentSession` 保存进程内会话交换，尚不是规划中做上下文选取与摘要的 `AgentMemory`。`PromptRepository` 负责模板加载、快照及渲染，不等同于仅拼接字符串的 `SystemPromptBuilder`。因此没有机械引入 `client`、`memory` 或重命名所有模型对象。

包调整只在稳定职责边界上进行：新增 `agent/tool/annotation/` 存放注解；工具契约和执行器仍在 `agent/tool/`，避免额外深层级。framework 的 `api/event/eventImpl/` 收平为 `api/event/`，`model/content/contentImpl/` 收平为 `model/content/`，因为各自目前只有一个或两个简单实现，单独实现包没有提供新职责。既有类仅改包路径，保留原作者和创建日期。

## 验证和实际轨迹

本地 JDK 21 下运行 `mvn -q clean test`，全项目通过。`ToolExecutorTest` 包含加法工具、参数错误、同名冲突与授权、执行异常及监听器异常、枚举列表、复杂类型拒绝和显式描述；此阶段没有调用真实模型。

```text
ToolCall(callId="call-1", name="add", argumentsJson={"a":2,"b":3})
PREPARING → 参数校验 → CALLING → Java add(2,3) → COMPLETED
ToolResult(callId="call-1", status=SUCCESS, content="5@run-1")

参数缺少 b → PREPARING → FAILED
ToolResult(callId="call-1", status=ERROR, errorCode=TOOL_VALIDATION_ERROR)
Java add 未被调用
```
