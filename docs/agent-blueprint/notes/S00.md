## 实际依赖图与运行入口

当前 `pom.xml` 聚合 `my-world-common`、`my-world-ai`、`my-world-app`。实际 Maven 依赖为：

```text
my-world-app（Spring Boot 启动及开发环境 HTTP 入口）

  │     └─→ my-world-common（共用对象与工具）
  └─→ my-world-common
```

启动类为 `my-world-app/src/main/java/com/dingbang/myworld/MyWorldApplication.java`。开发环境测试入口 `AiConnectivityController.checkConnectivity()` 构造 `AiChatRequest`，调用 `AiChatService.chat()`，由 `SpringAiChatAdapter.chat()` 调用 Spring AI `ChatClient`。当前 `chat()` 和 `stream()` 只传 `request.message()`；`conversationId` 被定义在请求中，但没有用于历史装配或持久化，因此不能把它视为会话记忆。当前服务返回文本或 `Flux<String>`，还没有 Agent 工具循环、状态和结构化事件。

S01 将新增的 `my-world-ai-app` 是接入代码生成等 AI 业务场景的普通 JAR；现有 `my-world-app` 是 Spring Boot 启动与 Web 入口。两者不会在 S00 中预先创建或改名。

## 阅读的参考方法

- `AgentClient.createSession()`：创建新的会话对象，帮助区分 Agent 定义与一次会话。
- `AgentClientSession.command(String)` 与 `command(String, List<MemoryMultipartFile>)`：将用户消息加入历史并构造结果句柄。
- `AgentClientSession.executeCommand(AgentSessionResult)`：组装消息和工具，再发起模型请求，说明参考实现已有 Agent 运行链路。
- `AgentSessionResult.execute()`：启动结果对象持有的执行器；注册回调与真正执行是两个动作。参考实现的具体调用语义以后按阶段核对，不在 S00 迁入。
