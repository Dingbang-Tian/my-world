## 当前存储实现

`AgentStorageConfiguration` 在 `my-world.agent.storage.type=mysql` 时创建 Agent 专用 Hikari 连接池，并装配 `MybatisSessionService`、`MybatisRunService`。两个 Service 分别通过继承 MyBatis-Plus `BaseMapper` 的 `AgentSessionMapper`、`AgentRunMapper` 访问 MySQL。默认 `memory` 模式仍可无数据库启动。数据库需预先创建；Flyway 从 `db/mysql/V1__agent_storage.sql` 校验或创建业务表。示例：

```yaml
my-world:
  agent:
    storage:
      type: mysql
      url: jdbc:mysql://127.0.0.1:3306/my_world?connectionTimeZone=UTC
      username: ${AGENT_DB_USER}
      password: ${AGENT_DB_PASSWORD}
```

`agent_session.state_json` 保存完整会话快照；`agent_message` 同事务保存逐条消息和唯一序号；`agent_memory_summary` 保存摘要覆盖位置，原始消息不删除。Service 用事务模板提交多表修改，Mapper 用版本、租约持有者和到期时间做条件更新。租约为 60 秒，每 20 秒续期；执行工具前再次验证。模型网络等待和 shell 执行期间不持有数据库事务。

`agent_run` 保存请求键、归属、父/根运行、模型和模板标识、终态；`agent_run_event` 保存按序查询的事件；`agent_tool_execution` 保存参数哈希及执行状态；`agent_plan`/`agent_plan_step` 保存计划状态；`codegen_artifact` 保存路径和哈希，不存整个文件。查询运行、事件与产物时校验 owner/app。数据库 JSON 不包含 API Key、模型客户端、线程或进程对象；请求附件字节不写入运行记录。原 H2/JDBC 实现与脚本已移至测试源码和测试资源，供既有恢复回归使用，不参与运行包装配。
